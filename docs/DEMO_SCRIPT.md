## 0:20–0:50 — Explain the workflow

**Screen:** README workflow and algorithm paragraph.

**Narration:**

“Eight proteins become a BLAST similarity graph. At each step, we solve cuts of
different fixed sizes, compare their normalized cuts using only the current
graph, and recurse. If the lowest-energy measured sample violates the size

comes from measured samples. Exact solving diagnoses the result; it never
replaces a failed quantum cut.”
